Scenario for Unity: every model in the editor

Generate images, video, 3D models, character animation, audio, PBR materials and skyboxes with every Scenario model, without leaving the Unity Editor. Retexture, edit, remesh, rig, animate or split a 3D model in place. Each request shows its price before anything is spent, and each result lands as a wired Unity asset.

Install Download the package Source on GitHub
Version {{version}}

For Unity 6.0 or later, with the Built-in pipeline, URP or HDRP. Install it from the Package Manager with the git URL, or download the .tgz package and install it from the tarball. Open source under the MIT licence.

How it works

You pick what to make, the window prices it for free, and one click sends it. The result is imported and placed where it belongs.

You pick

  • A type and a model
  • A prompt
  • Inputs from the Project or Hierarchy
  • A step on a selected asset

The settings form follows the model's live schema, essentials first.

Generate · 120 CU A free price check of this exact request

It lands as

  • A prefab on the ground
  • A sprite or a texture
  • A material on the mesh
  • An animated character
  • The scene's skybox

Every placement is one Undo step. Each generated asset records its model, prompt, job and cost, and shows them in the Inspector. AI agents drive the same actions through a local MCP server in the editor.

Install

Unity 6.0 or later. Tested on Unity 6.3 on macOS, with URP and with the Built-in pipeline.

From the git URL

  1. In Unity, open Window > Package Management > Package Manager, press + and choose Install package from git URL.
  2. Paste: 
    https://github.com/scenario-labs/unity-plugin.git?path=/Packages/com.scenario.unity#unity-plugin-v{{version}}
    The #unity-plugin-v{{version}} at the end pins this release; without it, the package follows main. It pulls in glTFast (Unity's GLB importer) and Newtonsoft JSON.
  3. Open Window > Scenario (Alt+Shift+S).

From the tarball, without git

  1. Download the package, com.scenario.unity-{{version}}.tgz. The releases page lists it with its SHA256SUMS and a build attestation: gh attestation verify com.scenario.unity-{{version}}.tgz -R scenario-labs/unity-plugin.
  2. Move the file into your project's Packages/ folder. Unity reads the package from that file for as long as the project uses it, so keep it there.
  3. In the Package Manager, press +, choose Install package from tarball and pick the file.

This package replaces the earlier Scenario plugin for Unity (com.scenarioinc.scenario, v0.11.0 and before). Remove it in the Package Manager, then install this one.

Sign in

  • Sign in with Scenario opens your browser. Approve, go back to Unity, pick a team and a project: generations are billed to that project.
  • Use an API key instead: paste the key and secret from the Scenario web app. The key is tied to one project.
  • CI and batch mode: set SCENARIO_API_KEY and SCENARIO_API_SECRET.

Secrets never go into the Unity project: they live in the macOS Keychain, the Windows Credential Manager, or a file readable by your user only.

Create

Pick a type, a model and a prompt. Inputs come from the Project window or the Hierarchy by drag and drop, or from a capture of the Scene view.

TypeLands in Unity as
Imagea texture or sprite, set on the selected SpriteRenderer, UI Image, RawImage or renderer
Videoa VideoClip on the selected VideoPlayer, or a new screen quad
3Da GLB imported as a prefab, placed on the ground at the Scene view pivot
Motionan animated GLB with an Animator Controller, one state per clip
Audioan AudioClip on the selected AudioSource, or a new one
Materiala material for the active pipeline with normal, height and packed maps
Skyboxa Skybox/Panoramic material set as the scene's skybox

3D: every operation

A generated or imported model opens the 3D steps in its Next menu: texture, shape, rig and animate, parts and style. Each step opens with its default model and the model already attached, so the price shows before anything is sent.

A rig delivered with walk and run files becomes one character with every clip in its controller. Results stored as FBX, Blender or VOX files arrive as GLB, skins and animations included.

Agents (MCP)

Turn on Agent in the window and the editor serves an MCP server, scenario-unity, on 127.0.0.1 with a bearer token kept on your machine.

Claude Code, Codex, Cursor and VS Code get Scenario tools (find a model, price, generate, import), scene tools (inspect and change objects, assign materials, capture the Scene view) and world tools (terrain, scatter, light and mood, a playable character and playtests). Every scene edit is one Undo step, and a paid call above the per-call limit or the session budget waits for Approve in the window.

Prices and spending

  • Price first. The button reads Generate · 11 CU, from a free price check of the exact request.
  • One click, one paid request. Each price is used once, and a paid request is never retried.
  • Uncertain means Unknown. If the connection drops while a paid request is being sent, the same request waits until it is matched on Scenario.
  • Confirmation above a threshold, and a spending switch in Settings that turns paid calls off.
