# Support

Scenario for Unity is an open-source editor package maintained by Scenario. This
page says where to look and whom to ask.

## Using the package

- Start with the [user guide](Packages/com.scenario.unity/Documentation~/USER_GUIDE.md),
  including its troubleshooting section.
- For models, Creative Units and account settings, see the
  [Scenario Knowledge Base](https://help.scenario.com).
- For release changes, read the [changelog](Packages/com.scenario.unity/CHANGELOG.md)
  and the [releases](https://github.com/scenario-labs/unity-plugin/releases).

## Bugs, change requests and questions

Use the [issue chooser](https://github.com/scenario-labs/unity-plugin/issues/new/choose).
Search the [existing issues](https://github.com/scenario-labs/unity-plugin/issues)
first. For a question, open a blank issue with a title starting with "Question:".

Before filing a bug, collect:

- The Unity version (Help > About Unity), the render pipeline and your operating system.
- The package version from the Package Manager.
- The output type, model and steps to reproduce, what you expected and what happened.
- The report from Settings > Diagnostics in the Scenario window, and relevant
  lines from the Console.

Public issues and attachments are visible to everyone. Never include an API key,
a secret, a token, a signed download URL or confidential project files.

## Account, billing, credits, API keys and security

Keep these matters out of public issues. Write to
[support@scenario.com](mailto:support@scenario.com) or use in-app support at
[app.scenario.com](https://app.scenario.com). Report security vulnerabilities as
described in [SECURITY.md](SECURITY.md).

## What to expect

Package issues are handled on a best-effort basis, without a response-time
commitment. Support for your Scenario account or subscription goes through the
Scenario channels above.
